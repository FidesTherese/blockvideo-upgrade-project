# D30 機能候補版の起動・方式切替

通常の画面とAPIを、専用DB・動画保存先で起動します。検証用の方式は
「検索なし（全操作から判断）」と「状態付き検索」の2つです。
画面の「操作の判断方式」は起動設定です。索引やモデルの正常性を保証する表示ではありません。
通常の設定・プロジェクトや `.env` を変更しません。

## 準備と起動

1. READMEの依存環境を用意し、frontendで `pnpm build` を実行します。
2. LM Studioで会話モデルを読み込み、ローカルサーバーを127.0.0.1:1234に起動します。
   今回の検証モデルは `ternary-bonsai-27b-heretic-ja`、context 8192、reasoning noneです。
3. 状態付き検索にはD27のmultilingual-e5-small用の公開済み索引とモデル資産が必要です。
   [索引作成](operation-index.md)と[意味検索](semantic-retrieval.md)を参照してください。
4. backendで次を実行します。保存先は空のディレクトリを指定してください。

```powershell
.\.venv\Scripts\python.exe -m scripts.plan_c_demo --storage C:\BlockVideoDemo --index C:\path\to\index-e5
```

メニューの `1` が検索なし、`2` が状態付き検索です。
ブラウザーで `http://127.0.0.1:8765` を開きます。
`--model` と `--port` でモデルIDとポートを変更できます。
索引がない場合、`--mode all_tools` を指定すれば検索なしだけを起動できます。

方式を切り替える場合は、生成完了を待ってターミナルでCtrl+Cを押し、同じ保存先で
もう一度起動してください。ブラウザーを再読込すると方式表示が変わります。
同じDBを2つのサーバーから開くことはできません。起動時のロックで防止します。

## 確認する操作

新規作成で「デモ用: 外部APIを使わずFakeProviderで実行する」を選んでください。
この選択は台本分割・画像・音声を合成データにします。言葉で操作するAIには実モデルを使います。

- `字幕を大きくして` → 変更量の質問。`64px` と回答 → 1回保存、生成なし。
- `動画をメールで送って` → 未対応、変更なし。
- `現在の設定で動画を生成して` → 対象・版の確認。その後に開始ボタンを押すと生成。
- 生成中の `話速を1.2倍にして` → 拒否。変更予約・自動取消・別操作への置換なし。
- 完成動画を再生し、再生成しても過去の成功動画が履歴に残ることを確認。
- 方式を切り替え、同じプロジェクトの設定・履歴が残ることを確認。

短い動画では生成中の操作を間に合わせにくい場合があります。D30の自動実演では
専用の検証ホストで動画組み立て直前を一時保留しました。この通常ランチャーには保留機能はありません。

検索結果は候補であり実行許可ではありません。共通コアが対象・引数・版・現在の状態を検証します。
同じ要求IDの再送は元の結果を返します。別の内容で同じIDを使うと拒否します。
