# D18 実装・検証報告

## 結果と合意した配置

プロジェクト詳細画面の上部に、対象・自然言語入力・確定結果を縦に並べるUIを実装した。
ユーザーが選んだ配置に従い、既存の設定フォーム、生成ボタン、設定履歴、動画履歴を残した。
元の計画書にある人間の確認欄は変更していない。

設定変更は送信後に保存し、変更前後の値、保存した版、動画への反映状態を表示する。
動画生成・再試行は対象・設定の版・生成内容を示し、明示的な開始操作を待つ。
生成受付、進行中、動画完成、失敗、停止を分け、モデルの自由文では成功を判定しない。

## 実装

- `language-types.ts` とAPIクライアントがD17のHTTP契約を表す。バックエンドの実行契約は変更していない。
- `language-storage.ts` は同じタブのsessionStorageに、要求ID・文章・対象・基準revision・送信種別を控える。
  保存できない場合は送信前に止める。キャッシュした応答を成功の根拠にはしない。
- `useLanguageRequest.ts` は明示的な新規依頼に新IDを発行し、再送では元のID・本文・版を保つ。
  送信中の二重クリックを防ぎ、対象と要求を照合し、古い画面からの遅い応答が新しい要求を上書きしないようにする。
  再読み込みと解釈中のポーリングはGETのみ。生成確認を自動再送しない。
- 応答不明時は新しい変更を待機させ、照会・同一要求の再送を提供する。
  周囲の設定・履歴は再取得するが、応答不明の要求そのものを成功とは表示しない。
- `LanguageResultCard.tsx` はコアの確定値と設定履歴から差分を表示する。
  後の変更がある場合は現在の版を別に示す。履歴が遅れている間は確認中として扱う。
- `LanguageVideoState.tsx` はジョブと利用可能な成果物を照合する。受付だけで動画完成にはしない。
  `LanguagePanel.tsx` が入力・送信状態・結果をまとめ、設定を戻すリンクは既存の履歴選択へ移動する。
- 不足情報、未対応、実行不可、エラーを分ける。聞き返しの続きは完全な依頼文として入力し直す。
  会話の文脈を持つD19の機能を先取りしていない。

## 実際に行った確認

合成プロジェクト1件、独立DB、選択済みのTernary Bonsaiへの実接続で、ブラウザーから操作した。

| 確認 | 結果 |
|---|---|
| 通常の設定変更 | 字幕48→56→60pxを保存。生成ジョブは増えない |
| 送信の二重クリック | 保存は1回だけ。結果は確定した差分 |
| 保存後の画面再読み込み | GETで元の結果を復元。POSTを再実行しない |
| 生成確認の再読み込み | 確認待ちを保持。ジョブ0件のまま |
| 開始確認の二重クリック | 生成ジョブ1件、成功成果物1件 |
| 保存の応答だけを失わせて同じ要求を再送 | 相対変更60→62pxが1回だけ確定（版3→4） |
| 別の応答消失後に再読み込み | 62→64pxの確定結果へGETで復旧（版4→5） |
| POSTを5秒遅らせて再読み込み | 未登録の照会を不確定として表示。同じ要求の再送で確認待ちへ復旧 |
| 確認待ちの間に既存フォームで70pxを保存 | 版5の生成提案を無効化し、古い確認から開始できない |
| 最新設定で再生成 | 版6・70pxの動画が完成。版3の旧動画も保持 |
| 生成中に「字幕を80pxにして」 | 実行不可。70px・版6のままで変更なし |
| 「字幕を大きくして」 | 変更量を質問。設定変更・動画生成なし |
| 具体的な依頼へ編集して送信 | 70→72pxを版7として保存。動画未反映を表示 |
| 結果カードから設定履歴へ移動し版6を復元 | 70pxを新しい版8として保存。生成は増えず2件 |
| 390×844の狭い画面 | 入力・結果・履歴を操作可能。内容幅375px＝スクロール幅375pxで横はみ出しなし |
| モデルを停止して状態照会 | 接続エラーを表示。成功や変更とは表示せず、既存フォームは利用可能 |

ブラウザーの障害試験では、検証用ラッパーだけが保存完了後の応答を503に置き換えたり、
POSTを遅らせたりした。生成の待機表示確認には同ラッパーで5〜12秒の開始待ちを加えた。
これらは本番コードの動作・通常の応答時間ではない。
途中で応答不明時の周囲の状態更新が不足する点を見つけ、再取得と説明文を修正して再確認した。

最終DBには自然言語要求11件、コアの確定記録9件、設定版8、成功ジョブ2件、成功動画2件。
実行していない古い生成提案、生成中の拒否、聞き返し、接続エラーには対応する実行記録がない。
相対変更は版3→4と版4→5の2記録だけで、再送による追加変更はない。
