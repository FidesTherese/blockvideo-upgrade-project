## 実測で発見し、利用者の承認を受けて修正したこと

利用者は「今回、誤保存を防ぐ修正まで行う」を選択しました。設定の即時保存方針は維持します。

1. 「大きくして」を勝手に2px増とする提案：指定された量と方向を検査し、不足は質問へ。
   「少し」=2pxは維持。現在値からの計算・revision検査・保存は従来のcoreが担当します。
2. 短い回答で前の未保存設定が抜ける：明示された字幕値や、記録された他の設定・生成希望が
   提案から落ちた場合は部分保存を拒否。過去の提案は拒否判定のみに使い、値を自動補完しません。
3. 「速度1.2倍」を「文末の間0.5秒」とする提案：入力にない数値と、明示した話速の欠落を拒否。
4. LM Studioが存在しないモデルIDを読み込み済みモデルに置換：応答のmodelを照合し、
   不一致・欠落はmodel_mismatchで拒否。追加推論・別モデルへの再試行・設定変更は行いません。

これらは保存前の保守的な検査です。日本語の意味を完全に検証する仕組みではなく、
別の言い回しでは余計な質問が出たり、未検出の誤解釈が残る可能性があります。
ベクトル検索や意図分類をこの検査で置き換えていません。D26の検索とは別の責務です。
