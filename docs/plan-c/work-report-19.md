## 実装と使い方

- 「字幕を大きくして」への質問に「56px」だけで回答できる。
  「APIの読み方を登録して」への質問には「エーピーアイ」で回答できる。
- 画面で「新しい依頼」「質問に回答」「この依頼を訂正」を区別し、関連する依頼と質問を表示する。
  新規・回答・訂正には新しいIDを発行する。同じ要求の再送は元のID・本文・対象・版を保つ。
- 未実行の依頼はボタン、または関連付けた「今回は作らないで」などで取り下げられる。
  保存済み設定の復元や、開始済みジョブの停止は別操作。生成には引き続き明示的な開始確認が必要。
- 別操作によって設定が変わった後の回答、別プロジェクトへの回答、回答済みの古い質問は拒否する。
  blocked・unsupported・errorから別操作へ自動で切り替えない。

`language_turns` は要求ID、親要求ID、answer/correction/dismiss、本文、後続要求IDを保存する。
親要求IDの一意制約で後続は1件に制限する。要求受付のwriterトランザクション内で、
親の状態・対象・現在の版・後続の有無を確認して関連付ける。
コアの実行直前にも、同じwriterトランザクション内で後続を検査する内部ガードを追加した。
古い生成確認と訂正が競合しても、取り下げ後の古い内容が実行されない。
ガードはサーバーだけが渡す関数であり、モデルやHTTPから実装名を指定できない。
既存の要求照会・確定結果の再送は、現在の版や後続の検査より先に行う。

モデルには過去の本文・質問・構造化提案をデータとして渡し、今回の回答と組み合わせて解釈させる。
実行権限は渡さず、登録済みコアが最終検証・保存する。無操作を表す `no_operation` を追加した。
読み方・表記は関連するユーザー本文にある値に限定する（ひらがな・カタカナ等を正規化）。
指定されていないアクセントを補った提案、空の設定変更は質問へ戻す。
読み方の非空の追加は、モデル外で既存一覧に表記単位で統合し、他の登録を消さない。
質問が入力文をそのまま繰り返すだけの場合は、不足内容を求める案内へ置き換える。
アプリ側で質問に戻した場合も、元の構造化モデル出力は検証用に保持する。

APIの回答は、従来の入力に例えば次を加えた新しい要求として送る。

```json
{
  "request_id": "answer-new-id",
  "text": "56px",
  "target": { "selected_project_id": 1 },
  "base_revision": 1,
  "continuation": { "parent_request_id": "question-id", "relation": "answer" }
}
```

## 実画面・実接続で確認したこと

独立した合成DBにプロジェクトA/Bを作り、ローカルのTernary Bonsaiを接続してブラウザーで操作した。

| 確認 | 結果 |
|---|---|
| 字幕の曖昧な依頼→56pxと回答、回答を二重クリック | 48→56pxが1回だけ保存され、版2になった |
| 「違う、少し小さく」と訂正 | 56→54px、版3。元の版2の結果も保持 |
| 訂正後の再読み込み | GETで結果を復元。追加保存なし |
| APIの読み方を質問中にA→B→Aへ切替 | Bに質問は移らず、Aに戻ると質問を復元 |
| 「エーピーアイ」だけを回答 | APIの読み方を版4として保存。字幕54pxのまま |
| 生成確認に「今回は作らないで」と訂正 | 取り下げ。ジョブ0件のまま |
| 字幕の質問中に通常フォームから58pxを保存 | 版5。旧質問へ60pxと回答しても送信前に拒否、58pxを維持 |
| 旧質問をボタンで取り下げ、通常フォームで54pxを保存 | 版6。取り下げは設定を戻さず、フォーム保存だけが変更 |
| 390×844の画面 | 確認・訂正欄を操作可能。内容幅375px＝スクロール幅375px |
| 現在設定で生成、開始確認を二重クリック | ジョブ1件、成功動画1件。版6の54pxを使用 |
| 完成動画 | カードと履歴に反映済みと表示。ブラウザーで末尾まで再生、メディアエラーなし |

最後にモデルをアンロードし、HTTPから版2の回答を同じID・同じ本文で再送した。
元の版2の結果と後続要求IDが返り、現在の版6やジョブ数は変わらなかった。
取り下げた古い生成確認の直接実行は `dialogue_superseded` で拒否された。
最終DBは自然言語要求12件、対話記録12件、コア確定記録6件、Aの設定版6、成功ジョブ/動画各1件。
Bは版1・48pxのまま。聞き返し・未対応・取り下げには実行記録がない。
相対変更は版2→3、54pxの1件だけである。
