項目別の重複handlerは作らない。未接続項目があれば既存の専門検証を共有して接続する。

検証は通常フォーム/構造化コア/自然言語の確定経路/旧PATCHの保存値、対象、設定版、
影響工程、入力拒否を比較する。読み方変更は原稿・字幕表記を変更しない。
自然言語の読み方追加は既存辞書への統合、通常フォームは編集した全辞書の保存という
既存の意味の違いを保持し、同じ最終設定は同じ検証・保存・無効化サービスを通す。

操作一覧に実装済みと非対象を明示する。生成確認、要求ID、revision、履歴、停止の規則を維持する。
